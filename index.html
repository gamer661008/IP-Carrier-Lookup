📖 使用說明

  • 在輸入框中輸入要查詢的 IP 位址（支援 IPv4 格式）
  • 點擊「查詢」按鈕獲取該 IP 的定位資訊
  • 點擊「查詢我的 IP」按鈕可以快速查詢您目前的 IP 位址資訊
  • 查詢結果包括：國家、地區、城市、電信業者、經緯度、時區等詳細資訊
  • 支援查看 IP 地理位置的地圖連結
